
# My Portfolio

A React site that shows the projects I built in Level 2.

This portfolio showcases the projects I built while learning software development.

## Components

| Component | What it shows | Where its values come from | What it remembers |
| --- | --- | --- | --- |
| `Header` | my name and a line about me | typed into the JSX | — |
| `Hero` | my hero photo | `heroPhoto`, which calls `imageUrl` | whether the photo is in color |
| `Fortune` | a random fortune | a list and `randomNumber` | which fortune is showing |
| `Footer` | © and the current year | the year the page is opened | — |
| `SignupPagePortfolioCard` | my Signup Page project with its name, description, and links | variables inside the component | its likes |
| `GreetingCardGeneratorPortfolioCard` | my Greeting Card Generator project with its name, description, and links | variables inside the component | its likes |
| `ClickLabPortfolioCard` | my Click Lab project with its name, description, and links | variables inside the component | its likes |

- A button to show a new random fortune
